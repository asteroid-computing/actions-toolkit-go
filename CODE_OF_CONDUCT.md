# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone taking part in its issues, pull requests and other spaces is expected to uphold it.

## Reporting

Report unacceptable behaviour privately to the maintainers through the repository's [private reporting form](https://github.com/asteroid-computing/actions-toolkit-go/security/advisories/new), stating that it is a conduct report rather than a vulnerability. Reports are reviewed promptly and handled confidentially. The maintainers will act on them as set out in the Covenant's enforcement guidelines.
